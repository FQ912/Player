Требуется: Python 3.10 или новее.
Скачать:   https://www.python.org/downloads/

Шаг 1. Открыть cmd в папке проекта
Шаг 2. Создать .venv

    python -m venv .venv

Шаг 3. Активировать виртуальное окружение

    .venv\Scripts\activate.bat

Шаг 4. Убедиться, что зависимости стоят

    pip list

Если чего-то нет:

    pip install pyqt5 pygame pylint

Шаг 5. ТЕСТЫ 
1)
    python -m unittest test_linked_list.py -v

Ожидаемый результат:

    Ran 14 tests in 0.0XXs
    OK
2)
    python -m pylint linked_list.py player_gui.py main.py

Ожидаемый результат:

    Your code has been rated at 10.00/10

Шаг 6. ЗАПУСТИТЬ ПЛЕЕР

    python main.py

Откроется окно "Плеер"

УПРАВЛЕНИЕ

Добавить   — выбрать .mp3/.ogg/.wav, ввести название и исполнителя
Удалить    — удалить выделенный трек
Вверх/Вниз — переместить трек по списку
Играть     — начать воспроизведение выделенного трека
Пред.      — предыдущий трек (после первого — сразу последний)
След.      — следующий трек (после последнего — сразу первый)
Стоп       — остановить воспроизведение
Двойной клик по треку — начать воспроизведение
